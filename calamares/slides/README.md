# Calamares slides

Recursos remotos utilizados por el slideshow personalizado de N.E.E.B.L.E.S. OS.

Los recursos siguen una convención numérica de slots:

1.png
2.png
3.mp4
...

Se admiten imágenes:

- png
- jpg
- jpeg

Y vídeo:

- mp4

N.E.E.B.L.E.S. puede preparar los recursos progresivamente durante la instalación, con un máximo de 20 slots.

Si no hay red o no existen slides remotos válidos, N.E.E.B.L.E.S. utiliza el fallback local incluido en la ISO.


## Estado de integración — 2026-10-04

La integración de slideshow localizado se mantiene como feature de N.E.E.B.L.E.S. OS y no debe interrumpir el cierre de Boss/Test Module. La lógica fuente y su material Calamares permanecen como trabajo ya integrado; la siguiente validación completa se realizará cuando se reconstruya la próxima imagen de OS.

No se declara una ISO nueva ni una aceptación final de instalación desde este checkpoint.
